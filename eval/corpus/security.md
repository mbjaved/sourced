# Information security

Passwords and access.

Laptops must use full-disk encryption and lock after 5 minutes of inactivity. Two-factor authentication is mandatory for email, source control and the finance portal.

Incidents.

Report a lost or stolen device to the security team within 1 hour, by calling the security hotline. Never try to recover a phishing email yourself; forward it to the security team instead.

Customer data.

Customer data must stay in the EU region. Copying customer data to personal devices or personal cloud storage is forbidden.
